The Funniest Sick-Day Excuse: **I can't come in — my immune system unionised overnight and is demanding better working conditions.**

The funniest sick-day excuse in one line: the immune system unionised overnight and is demanding better working conditions. Half believable, fresh idea, twist at the end. The other candidates — 'aggressively horizontal' and the cat-as-HR complaint — are kept in `vA/`, `vB/`, `vC/`; vA was chosen because its idea is the freshest and its punchline lands last.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 26.13.1 per the kit).
The program writes exactly the entry above to `/output/entry.txt` — no
trailing newline, so the file holds exactly the entry — and prints exactly
that text to stdout. It uses no network, no randomness, no clock and no
environment input, so two runs produce byte-identical output.
